# 外观设置与主题兼容

## 界面与生效范围

外观设置由 `AppearanceSettings` 展示，包含主题、强调色、前景／背景色、字体和可折叠的高级设置。
高级设置包括界面／代码字号、减少动态效果、独立浅深色配置、三类字体及字重、半透明侧栏、对比度、差异标记和指针光标。

- 主题菜单提供 ChatGPT、纸张、午夜配色，以及跟随系统、浅色和深色模式。复制主题以当前解析后的颜色生成可编辑副本。
- “管理主题与背景…”保留原有图片主题、预览、创建／编辑、导入／导出、缩放和侧栏宽度功能。
- 颜色与排版通过既有全局 CSS token 生效，不依赖懒加载的设置页面。代码字体、字号和字重同时作用于聊天代码、Git 差异正文和工具差异正文。
- 字号支持 10–24 的整数；空值或非法输入不会写入偏好，失焦恢复当前合法值。
- 颜色只接受六位 HEX；前景／背景配置为 `null` 时使用当前主题及模式的默认颜色。对比度为 0–100 的整数，用于调整边框和分隔线的强度。
- 字体仅选择本地字体栈，不下载或安装字体；缺少指定字体时使用系统回退。
- “减少动态效果”支持 `"system"`、`true`、`false`。显式关闭优先于系统设置；系统模式响应媒体查询变化。
- 差异标记可切换颜色或正负符号，覆盖 Git 和工具差异视图；指针光标只改变可交互元素的鼠标样式。

## 偏好 schema 3

当前存储键为 `pi-desktop.app-preferences.v3`，依次回读 v2 和 v1 的旧键。读取旧配置时保留已有字号、字体、侧栏透明度和明确的动画选择，补齐新增字段；保存时写入 v3，不删除旧键。
旧版本应用不能解析新字段，也不会获得之后的 v3 更新；兼容方向是新版本读取旧数据。

`appearance` 的公共类型定义在 `apps/desktop/src/ipc/appearanceTypes.ts`：

- `profile`：共享的主题、颜色、字体／字重及对比度。
- `separateModes`、`lightProfile`、`darkProfile`：是否启用及各模式的独立配置。
- `diffIndicators`：`color` 或 `symbols`。
- `pointerCursor`：是否显示指针光标。

首次启用独立模式时，从当前配置补齐缺失的浅／深色配置；已有模式配置不会被覆盖。切换模式只编辑对应配置。关闭独立模式后，以当前可见模式作为共享配置，同时保留独立配置，便于再次启用。
字号、缩放、图片背景、半透明侧栏、动画、差异标记和光标仍是全局偏好，不随浅深色模式分别存储。

新安装默认跟随系统主题，使用 ChatGPT 配色、14 px 界面字号、12 px 代码字号、常规字重、对比度 45、半透明侧栏、系统动画偏好、颜色差异标记和普通光标。
存储不可用时设置仍可在内存中使用，但不能承诺跨重启保留。

## 主题文件 schema 2

Rust 外观命令导出 schema 2，导入接受 schema 1 和 2。
新增可选的 `appearance` 与 `reduceMotion` 字段，旧文件缺失时由 Rust 返回 `null`；Renderer 不以这些空值重置当前新偏好。
旧的字体、字号、背景、缩放、侧栏配置仍可导入。新版导入同时恢复共享／独立配色、字体样式、动画、差异和光标设置。

Rust 对主题版本、主题名、HEX、字体枚举、字重、对比度、字号和动画选项校验；未知版本及非法输入返回稳定错误。
主题文件仍遵循原有文件大小、背景图片和路径校验，不扩大文件系统权限，不改变 Bridge 协议版本。
所有文件选择及读写继续经 `src/ipc/appearance.ts` 和 Rust command，不在展示组件中直接访问 Tauri、文件系统或进程。

## 验证

- `pnpm --dir apps/desktop test --maxWorkers=2`：全量前端回归与覆盖率。
- `pnpm test:runtime`、`pnpm --dir agent-bridge test`：运行时准备及 Bridge 回归。
- `cargo test --manifest-path src-tauri/Cargo.toml`：包含新旧主题兼容、配置往返及非法字段测试。
- `pnpm check`、`pnpm build`：包含 TypeScript 和 Rust 检查／构建。
- 界面验收、同图比较与已知限制见根目录 `design-qa.md` 的“2026-09-26 外观设置复刻”章节。

浏览器隔离预览验证了真实 Renderer 控件和样式；系统文件选择／保存对话框由 IPC Mock 与 Rust 文件 fixture 覆盖，未将其描述为原生窗口端到端手测。
