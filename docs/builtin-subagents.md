# ADR-005：桌面内置子代理

日期：2026-09-28。状态：已采纳。

## 决定

Bridge 在父会话中注册应用自有的 `subagent` 工具，支持单任务、最多 4 个并行任务和顺序任务链。每个任务使用官方 SDK 的 `createAgentSession` 与 `SessionManager.inMemory`，不调用 CLI、不启动额外进程、不重写 Agent 循环。Renderer、Rust 协议与已有子代理侧栏继续消费 `subagent` 工具结果及流式更新。

- 子代理继承父会话的工作区、实际模型、思考强度及已启用的官方内置工具子集；共享已加载的 ModelRuntime，不复制认证信息。
- 子会话不自动加载用户扩展、模板或技能，不注册委派工具，防止递归派生及第三方工具绕过继承规则。项目 AGENTS/SYSTEM 上下文仍由官方资源加载器读取。`agent` 是本次任务的显示名称，不是第三方插件的 agent 配置文件名。
- 子工具复用父会话的审批与文件审查钩子，审批显示在父会话，工具调用 ID 隔离；停止或关闭父会话级联取消子任务及待决审批。
- 独立子上下文仅接收明确委派任务；主模型仅收到结果摘要。侧栏独立读取完整的真实用户任务、assistant/thinking/tool 消息与工具输入/输出，不限制总条数或正文长度。父工具结果的 `details` 仅携带有界预览及完整记录的可用性/版本；禁止把完整 transcript 塞进主模型文本结果。
- 完整脱敏记录通过官方父 SessionManager 的 `pi-desktop-subagent-transcript-v1` custom entries 分片保存，以 commit 与 SHA-256 校验完整性；侧栏使用 `subagent.transcript` 分页读取，单页编码文本最多 64000 UTF-8 字节，分页不丢弃内容。任务执行中通过 `onUpdate` 更新快照，完成、失败和取消后保存已有完整内容；保存失败明确报错并保留当前窗口内存记录，不冒充成功落盘。进程意外退出前尚未保存的运行中内容不保证恢复。
- 第一版不提供后台任务、对子代理追加消息、单独取消或第三方 agent 配置导入；主会话停止可取消整组任务。
- 内置实现验证通过后，再通过官方 Pi 包管理流程卸载全局 `npm:pi-subagents`，避免重复工具注册。历史第三方结果仍保留兼容投影。

## 使用

在主会话直接要求“派两个子代理分别检查前端与 Bridge，再汇总结果”，由主模型调用内置工具。展开主时间线中的子代理任务组，点击卡片即可在右侧只读标签查看实际委派内容、回复、思考和工具输入/输出；重新打开父会话可恢复已保存的记录。

支持单任务、最多 4 个并行任务或最多 4 步顺序任务链；后一步可使用 `{previous}` 引用前一步结果。子代理使用主会话当前模型和权限，涉及审批的操作仍由主会话确认。停止主任务会取消整组子任务。

升级后需重启桌面应用使 Bridge 加载新实现；已运行的会话可能仍持有旧扩展实例。无需在 CLI 安装或启用子代理插件，也不自动导入旧插件的 agent 定义。

旧版已经裁掉且未保存的正文无法凭空恢复，侧栏明确提示旧记录不完整。安全脱敏仍适用；当前不归档图片 Base64 或递归子代理快照。

## 验证

使用 Mock SDK 验证注册、模型与工具继承、实时/终态 transcript、并行隔离、任务链、输入边界、取消创建中任务、异常清理、审批和审查路由、重开历史。使用本地官方 SDK 与隔离配置做无网络集成验证。执行仓库测试、类型检查和构建后才能移除第三方包。

`node --test scripts/test-builtin-subagents.mjs` 使用本地官方 SDK，仅替换模型传输与认证为确定性 fixture，并禁止网络请求。验证父会话调用子代理、子代理执行真实 SDK 写文件工具、父会话文件审查、流式记录以及关闭/重新打开父会话后的历史恢复。测试不会读取真实密钥，也不代表完成在线模型端到端手测。默认读取应用准备好的 Pi runtime，可通过 `PI_SUBAGENT_TEST_SDK` 指定官方 SDK 的绝对入口。
