# 常规设置：网络与电源

代理入口合并到「常规」，旧代理导航标识保留为兼容别名。沿用独立的 AI / 应用代理配置；统一选择器会明确同时修改两者，已有不同配置不自动覆盖，可展开分别配置。代理配置版本和支持的协议不变，不增加 SOCKS 或认证代理。

## 配置与迁移

新增应用配置目录 `general-settings.json`，`schemaVersion: 1`，含 `relaxedNetwork`、`keepAwakeWhileRunning`、`preventScreenSleep`。不存在该文件的旧安装迁移为宽松网络开启、电源选项关闭，以保留现有连接行为。无效类型、未知版本或损坏配置不静默回退。与 `proxy-settings.json`、Pi 原生配置及 Renderer 本地工作台偏好分离。

## 网络边界

参照 PI-Desktop 的宽松模式，允许用户配置的本机 / 局域网 HTTP 服务及 TUN fake-IP。关闭后 Bridge 的全局 Undici HTTP 客户端仅允许公网 HTTPS；解析失败和非公网地址拒绝访问。不关闭 TLS 证书验证。保存策略会重启 Bridge 并中断当前生成。应用更新仍使用原有 GitHub HTTPS 白名单。

这不是网络沙箱；外部 Git、外部浏览器以及不使用全局 Undici 客户端的 SDK / 扩展保持自己的网络策略。内置浏览器保持用户主动导航语义，不把网页流量混入 Agent 网络策略。不承诺支持当前项目尚未实现的 MCP 或市场源。

## 电源生命周期

Windows Rust Core 使用专属常驻线程调用 `SetThreadExecutionState`，分别控制系统空闲休眠和屏幕空闲关闭。阻止屏幕休眠也需要维持系统唤醒。不会阻止用户主动休眠、合盖或电源键操作。窗口最小化或隐藏到托盘时继续生效，应用真正退出时在同一线程清理。其他平台明确提示暂不支持并禁用电源开关。

电源设置立即生效，系统调用失败不落盘，持久化失败尝试恢复原系统状态。启动时恢复已保存状态，恢复失败在设置页显示错误。所有 IPC 集中在 `ipc/`，组件不直接使用 Tauri。独立 CSS 仅作用于常规网络 / 电源，不修改开屏动画或全局样式。

## 验证方法与限制

- 网络测试覆盖私有／保留／fake-IP 地址、公网 IPv4／IPv6、混合 DNS 答案和解析失败；使用本地 CONNECT fixture 验证先匹配原始域名的 NO_PROXY，再固定目标 IP，连接器测试验证保留 TLS SNI。测试不访问真实模型服务，也不关闭证书验证。
- 电源测试使用 Mock 后端验证系统／屏幕请求、同线程清理、持久化失败回滚、回滚失败恢复和退出释放，不改变开发电脑的真实电源设置。Rust 原生行覆盖率未测量；Windows API 的实际系统行为仍需手动验收。
- Renderer 使用 Mock IPC 验证加载、重试、损坏配置显式重置、异步卸载、重复提交、分段选择、开关与帮助浮层。新增常规／代理控件、状态管理和 IPC 的专项行覆盖率为 100%，分支覆盖率 97.43%；网络策略模块行／分支覆盖率为 100%。
- 共享 debug 资源被运行中的应用占用时，改用临时独立 `CARGO_TARGET_DIR` 验证；不结束开发进程、不覆盖用户开屏文件。`pnpm build` 已在该独立目录成功。
- 浏览器工具认证不可用，尚未完成同视口截图对比；详见仓库根目录 `design-qa.md` 的本次任务记录。未把 DOM 测试或源码检查当作视觉验收通过。
